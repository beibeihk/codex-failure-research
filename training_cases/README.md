# Training-case policy

No model training trajectory is published in v0.1.0. The confirmed failure is
in harness feedback propagation, so it belongs in a software regression eval.
Scripted Responses output is not real model behavior or a post-training dataset.

Future model-layer cases must specify task/environment, synthetic trajectory
summary, desired invariant and an objective verifier. Model-output rights,
privacy, grader validity and alternative explanations must be reviewed before
publishing any trajectory. A verifiable reward proposal is not a trained model
or evidence of an RL improvement.
